# godot_chess

Roguelike chess, ported from the TypeScript/Electron prototype to Godot 4.7 (.NET). See [docs/PORT_PLAN.md](docs/PORT_PLAN.md) for the plan and the reasons behind the redesign.

## Layout

| Path | What |
|---|---|
| `src/RogueChess.Engine/` | Rules engine: state, moves, turn resolution, content, AI. Pure C#, **no Godot reference**. |
| `tests/RogueChess.Engine.Tests/` | xUnit tests for the engine. |
| `sandbox/` | Interactive debug sandbox (main scene): load scenarios, play both sides, edit positions, read the resolution trace. |
| `maps/` | `sandbox/` scenarios (generated by `tools/make_scenarios.py`) and `legacy/` maps from the TypeScript prototype. |
| `docs/` | [Plan](docs/PORT_PLAN.md), [resolution rules](docs/RESOLUTION_RULES.md), [content guide](docs/CONTENT_GUIDE.md). |

## Requirements

- Godot **4.7.2 .NET** (the `mono` build). The standard build can't run C# scripts.
- .NET SDK 8 or newer.

## Commands

```bash
dotnet test tests/RogueChess.Engine.Tests/RogueChess.Engine.Tests.csproj
```

```bash
dotnet build GodotChess.csproj
```

Open the project in Godot .NET and press F5 to run the sandbox. Each turn's trace is also printed to the output log as `[Sandbox] ...`.

Regenerate the sandbox scenarios after editing `tools/make_scenarios.py`:

```bash
python tools/make_scenarios.py
```

## Ziva

The Ziva editor add-on is installed per machine into `addons/ziva_agent/` (gitignored, not redistributable). Copy it from another project or install it from ziva.sh.

AI opponents (profiles, per-level injection, tuning): [docs/AI.md](docs/AI.md).

Battles are meant to be short, on small boards (6x6). The sandbox's Encounters row generates the prototype's roguelike battles from `encounters/prototype.json`; see the design direction in [docs/PORT_PLAN.md](docs/PORT_PLAN.md).
